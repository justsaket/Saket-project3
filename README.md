# Animated Palace Clone

Vercel-ready Next.js implementation of the Animated Palace experience.

The build downloads a pinned public source snapshot and then runs Next.js, preserving the GSAP ScrollTrigger animation, Lenis smooth scrolling and cinematic frame sequence.

## Vercel
- Framework: Next.js
- Root Directory: `./`
- Build Command: `npm run build`

## Gemini watermark
No Gemini watermark/UI component was found in the public source code. This project does not add a Gemini watermark overlay. If a watermark is visibly baked into a generated image/video asset itself, it is part of that asset and must be replaced at the asset level rather than hidden with CSS.

Source reference: https://github.com/Code2With-Pratik/Animated-Palace-Website
